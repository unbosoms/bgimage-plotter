2. 点を置く

クリックで点を追加 → 名前を入れて Enter。
点をドラッグで移動、クリックで名前の修正。
Delete：選んだ点を削除／Ctrl（Mac は ⌘）+Z：最後の点を取り消し
名前のリストから順に付ける（任意）
1行に1つ。クリックするたびに上から使い、使った行は消える。空になったら入力欄が出る。

4. 書き出し

5. Tableau での設定

画像を読み込むと表示します。
  1. CSV をデータソースにつなぐ（X・Y は数値（小数））。
  2. ［マップ］＞［背景イメージ］＞ データソース ＞［イメージの追加］で、同じ画像と上の値を入れる。
  3. X を［列］、Y を［行］に置き、右クリックで［ディメンション］にする（集計しない）。
  4. 軸がずれるときは、両方の軸を［軸の編集］で上の範囲に固定する。
画像の形式は PNG・JPEG を使う（WebP は Tableau で読めないことがあるので、PNG に変換しておく）。
